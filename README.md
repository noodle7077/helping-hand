# Helping HAND

A dream by ne0Relix. **BETA — still being worked on.**

[Play on itch.io](https://nood777.itch.io/helping-hand) · [Play on GitHub Pages](https://noodle7077.github.io/helping-hand/)

Explore ten randomized neighborhoods, then unlock ten heaven neighborhoods with cloud ground, halos and quiet atmosphere instead of music. Each level selects twelve of 24 collage NPCs and twelve of nineteen pickups. Return their belongings with a four-item pocket. Four wrong offers make an NPC chase and attack; zero health sends you into the clouds. Both Rebirth buttons return you with full health.

Timers fall from ten minutes to five over each stage. Menus and dialogue pause the timer, each elapsed minute chimes, and running out offers a level retry.

WASD move · mouse look · Shift run · Space jump · 1–4 select pocket item · E collect/talk/offer · J requests · M map · Esc pause. Enter Neighborhood requests fullscreen and mouse capture. Sound and decorative motion are adjustable. Progress stays in your browser. Completed levels from the earlier version remain approved; incomplete old visits restart to support new randomized assignments.

Art, logo, graffiti and music supplied by ne0Relix. Browser implementation, dialogue, synthesized effects and some character/hand graphics developed with Codex and image generation. Three.js is bundled under its MIT license in assets/THREE-LICENSE.txt.
