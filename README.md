# Helping HAND

A dream by ne0Relix.

Play at https://noodle7077.github.io/helping-hand/ in a desktop browser.

A surreal first-person collage game: ten randomized neighborhoods, 24 residents and twelve lost objects in each, photographic skyboxes, flying crows, wall graffiti and original music. Return the objects to their owners to open the next neighborhood.

WASD move, mouse look, Shift run, Space jump, E interact, Esc pause, J requests, M map. Click Enter Neighborhood to capture the mouse. Progress is saved in your browser. Sound and decorative motion can be adjusted in the game.

Art, logo, graffiti and music supplied by ne0Relix. Browser game implementation and synthesized effects developed with Codex. Three.js is bundled under its MIT license in assets/THREE-LICENSE.txt. Wire frame: https://pngimg.com/image/18859, CC BY-NC 4.0 https://creativecommons.org/licenses/by-nc/4.0/, resized using CSS. No blanket license is granted for the other supplied artwork or music.

Static HTML/CSS/JavaScript. index.html is the entry point; assets are loaded using relative paths. .nojekyll lets GitHub Pages serve the files directly.
